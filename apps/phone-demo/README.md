# BookLoop 手机网页样品

独立的静态交互样品，适合让朋友先在手机查看页面与流程。打开体验链接即可使用，无需安装开发工具。

公开体验链接：https://xy-729.github.io/bookloop-market/

所有用户、审核、聊天回复、付款、退款和结算均为演示。记录只保存在当前浏览器，设备之间不会同步；页面没有真实支付或后台连接。请使用演示图片，不要输入真实身份材料。

本地预览：在项目根目录执行 `python -m http.server 4180 --directory apps/phone-demo`，打开 `http://127.0.0.1:4180/`。手机需要访问正式体验链接；本机回环地址不能转发给朋友。

试玩：找书 → 联系卖家 → 立即购买 → 模拟付款 → 在“我的”切换卖家并标记交付 → 切回买家确认收货。另买一本可体验退款。在“我的－样品说明与反馈”记录和复制意见。

原生微信小程序位于 `apps/miniprogram`。网页样品便于确认需求；正式小程序需要 AppID、服务器域名及微信审核，真实交易需要完成支付产品接入。
