# 微信小程序上线准备

当前版本可在本地进行模拟交易和接入测试。管理后台的“上线准备”和 `npm run check:release` 展示缺失条件，不会把环境变量或模拟测试当作真实验收。

## 账号和经营主体

在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序并取得 AppID。提交主体资料、扫码验证、接受平台协议以及支付认证费，应由账号所有者完成。密码、AppSecret、证书私钥和支付密钥只配置在部署环境，不提交到公开仓库。

注册前先明确经营主体和拟申请类目。个人账号可以用于学习和符合条件的功能，但不能据此认定已获得普通小程序支付权限或平台为个人卖家结算的能力。先咨询经营主体、平台准入及个人收款方案，再按获准产品申请账号与商户权限。

- [腾讯注册说明](https://kf.qq.com/faq/170109iQBJ3Q170109JbQfiu.html)
- [微信小程序支付接入](https://pay.wechatpay.cn/doc/v3/merchant/4015459512)
- [个人收款二手交易场景](https://pay.wechatpay.cn/doc/v3/partner/4012602295)：文档标注灰度阶段，实际开放及申请结果须向平台确认。

## 协议与隐私

开发者工具导入 `apps/miniprogram`，构建后有 14 个页面，包括隐私政策与用户协议。登录前阅读并勾选同意，后端记录版本与时间；协议更新或撤回后阻止新发布和新交易，已有订单的查询、交付、确认收货、退款与投诉继续保留。

正式构建关闭模拟身份和模拟隐私授权。图片上传前调用微信隐私授权，拒绝后不继续打开相册或相机。微信后台仍须配置《小程序用户隐私保护指引》，准确申报选定图片、用户标识等用途；平台内协议页不能代替微信后台声明。

`OPERATOR_NAME` 和 `SUPPORT_CONTACT` 填写实际主体与联系方式。协议是可审阅模板，运营方须补齐具体记录保存期限、投诉安排等真实条款，审阅后设置 `LEGAL_APPROVED=true`。生产上传前配置 `MINI_API_URL`、`MINI_APP_ID`，执行生产构建并核对产物。

## 内容审核与加密回调

`WX_CONTENT_SAFETY=wechat` 时，教材及聊天文字提交微信安全检测；未通过、要求复核或检测不可用时拒绝发布或发送。

教材、聊天和投诉图片异步审核，上传后为 PENDING，创建检测及 30 分钟超时任务。只有可信回调确认 APPROVED 后才公开展示或用于发布；失败和超时保持阻断。认证证明保持私有人工审核，不提交微信图片检测。

微信后台消息推送使用 **JSON 格式、加密模式**，地址为 `https://你的接口域名/v1/wechat/events`。部署环境配置 `WX_MESSAGE_TOKEN` 和 43 字符 `WX_ENCODING_AES_KEY`。服务器校验签名、时间、接收方、填充及检测结果；重复通知幂等，先于提交响应到达的回调暂存后关联。仅支持此配置，XML 与明文推送会被拒绝。

检测图片链接只提供签名授权的 JPEG，2 小时有效并禁止缓存；不提供认证证明。媒体桶与证明桶均禁止直接匿名读取，由服务按审核状态与权限提供图片。

旧认证证明保留管理员访问；无可信检测来源的旧公开／聊天图片不自动批准，需重新检测。初始化脚本仅恢复代码生成的内测演示图，生产环境不生成演示数据。

## 微信发货管理

标记交付时在数据库事务内创建 `WECHAT_SHIPPING` 任务。真实交易单号和付款人 OpenID 用于同步线下自提信息；失败退避重试，管理员可在异常队列处理。成功响应后才标为 SYNCED，模拟订单为 SKIPPED_MOCK。

生产结算须发货同步成功，重试成功后再检查结算条件。当前请求适用于普通微信交易单号的线下自提模型；获准产品使用合单、子订单或其他交付方式时，须按正式文档调整映射与接口，联调后设置 `WX_SHIPPING_VERIFIED=true`。实现同步代码不代表已开通微信发货管理权限。

## 实际发布验收

1. 注册、协议同意与撤回、认证、发布、图片审核、聊天和拒绝隐私授权。
2. iOS／Android 真机：弱网、重连、重复操作、超时和拒绝订阅消息。
3. 真实小额付款、退款、提前确认、7 天结算、72 小时未交付退款及对账。
4. 加密回调与重试、真实发货同步、图片权限和对象存储配置。
5. HTTPS、合法域名、数据库备份恢复、监控、客服及投诉安排。
6. 实际账号的类目资质、认证、备案、隐私声明和版本审核。

真实支付适配器仍缺失，检查保留支付阻断项。上述条件齐备后提交版本审核，由账号管理员完成正式发布。
