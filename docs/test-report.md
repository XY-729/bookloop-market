## 覆盖的主要业务

下单锁定及价格快照、禁止自买和未认证交易、15 分钟超时、迟到支付退款且不影响新订单库存、重复付款通知、金额校验、72 小时未交付退款、交付期限校验、提前确认、付款满 7 天结算、退款与结算并发互斥、退书确认、退款驳回恢复原计时、结算后投诉、多个投诉的解冻条件。

权限覆盖跨用户订单与会话、后台角色、封禁后的旧 token、认证材料私有访问、120 秒签名访问与删除后失效、旧证明不得重复提交、图片真实解码、图文修改重新审核、暂停交易期间的售后、管理员密码和敏感字段过滤。

消息与任务覆盖 WebSocket 鉴权接收、相同时间戳的消息游标、图片参与者权限、幂等消息标识、支付签名、渠道超时、任务失效租约恢复、失败任务重试、资金金额与流水对账、投诉聊天查阅审计。生产配置测试拒绝模拟支付、开发登录、未核验能力、开发密钥和非 HTTPS 域名。

测试过程中为数据库事务和消息并发分别建立真实 PostgreSQL 场景，未以内存数据库替代库存和资金约束。模拟支付不涉及真实资金。
