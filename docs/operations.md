# 运营操作手册

## 初始化与日常维护

运营负责人维护真实分类、主题、交付区域与交付地点。初始化的演示条目须在试运营前核对。公告说明教材范围、交易方式、72 小时交付时限、退款入口和结算规则；禁止用演示图片替代用户实拍图片。

每天打开工作台查看认证审核、教材审核、退款、投诉和异常任务队列；执行对账并保存检查结果。存在渠道差异时暂停新交易，先查付款、退款和结算记录。暂停不会中止已有订单的售后和资金任务。

## 用户认证审核

进入“用户认证审核”，按平台公布的认证要求核对申请材料。材料不充分时填写可操作的驳回理由；通过后才开放发布、购买和聊天。图片链接仅短时有效，不复制到外部群聊或公共公告。审核结束 7 天后系统删除原始图片；保留审核结论和操作记录。

## 教材审核

确认是学习教材，正反面照片清楚且不同，书名、版本、主题、分类和售价合理。错误描述应驳回说明。修改图文后重新审核，价格调整不影响已经下单的买家。下架已锁定教材会阻止新交易，并可能使后续付款进入自动退款补偿，需要同时跟进关联订单。

## 交付与退款

卖家应在付款后 72 小时内交付，并在实际交付后标记。买家未收到时可申请退款；卖家标记交付不代表买家确认。未交付超时自动发起退款。

退款申请进入队列后暂停结算。审核通过可选择“直接全额退款”或“先退书再退款”。后者须卖家确认收回教材，或管理员核实后确认，才会执行渠道退款。审核驳回后恢复原时间规则，不重新开始 7 天计时。

处理争议先查看订单时间、投诉证据及双方说明。退款完成仅指渠道已经明确确认成功；失败任务未恢复前不得向用户承诺已退款。需要退书但卖家长期不响应的订单，由管理员核实实际退书情况后处理，系统不会绕过退书确认自动退款。

## 结算和结算后投诉

确认收货或付款满 7 天且已交付、无纠纷时进入结算。资金记录中的“处理中”不代表已到账；以渠道确认流水为准。结算已发起或已完成后，不执行自动扣回卖家资金，保留投诉证据并人工协调。

投诉解决后记录具体结果及后续安排。所有未解决投诉均处理后，订单才解除纠纷暂停；到期订单随即恢复结算检查。若决定退款，应先批准相应退款流程，再关闭投诉，避免解冻后先行结算。

## 异常任务和账号处理

“任务与异常”查看任务类型、重试次数和错误信息。任务最多自动尝试 8 次，随后进入异常队列。管理员先查渠道是否已经成功，再使用原操作 ID 重试；不要手工创建第二笔转账。超过 5 分钟的失效任务租约会自动恢复。

封禁须记录原因。旧登录 token 随后失效，已连接聊天会在身份复查时关闭；已付款订单仍须运营人员跟进，必要时由管理员执行退书核实和售后处理。

重要资金成功事件、审核、退款批准、封禁、对账和手动重试均保留审计记录。自动资金操作的 actor 为空，避免把系统操作误记为用户行为。
